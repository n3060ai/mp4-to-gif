# MP4 → GIF 変換ツール

ブラウザ内だけで安全かつ手軽に MP4 動画を GIF アニメーションに変換できる、シングルファイル（HTML）の軽量ツールです。外部サーバーへの動画送信が一切ないため、プライバシー面も安心してお使いいただけます。

## 特徴

- 🔒 **完全ローカル処理**: すべての処理がブラウザ（JavaScript）内で完結するため、動画データが外部サーバーに送信されません。
- ⚡ **リアルタイムプレビュー＆設定変更**: 解像度（スケール）やフレームレート、切り出し位置（開始・終了時間）を自由に調整可能。
- 📊 **サイズ見積もり機能**: 本格変換の前に数フレームを試し変換し、大まかなファイルサイズを事前におおよそ見積もることができます。
- 🎨 **洗練されたダークUI**: 直感的でスタイリッシュな操作画面。

## 使い方

1. `mp4-to-gif.html` ファイルをブラウザ（Chrome, Safari, Firefox, Edge など）で直接開きます。
2. 画面上のドロップゾーンに MP4 動画ファイルをドラッグ＆ドロップ（またはクリックしてファイルを選択）。
3. 必要に応じて以下の設定を調整します：
   - **解像度**: スケールバー（10%〜100%）で出力サイズを調整
   - **フレームレート**: 滑らかさやサイズに影響する fps を設定
   - **開始・終了位置**: GIF化したい特定の部分だけをトリミング
4. 必要であれば「**概算サイズを見積もる**」ボタンでサイズを確認。
5. 「**GIFに変換する**」をクリックし、エンコード完了後に「**ダウンロード**」から保存します。

## 技術スタック

- **Vanilla JavaScript** (フレームワーク不使用の軽量設計)
- **HTML5 Canvas / Video API**
- **[gif.js](https://jnordberg.github.io/gif.js/)** (Web Workerを用いたブラウザ内GIFエンコーダー)
